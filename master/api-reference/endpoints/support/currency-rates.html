Currency Rates ​

Part of the Support API. Base URL https://your-domain.com/admin/api/v1 — replace the host with your own installation and the token placeholder with a real Bearer token (see Authentication).

List currency rates ​

GET /admin/api/v1/support/currencies/{currency_id}/rates

Retrieve a paginated list of currency rates for a specific currency with filtering and sorting

🔒 Requires a valid Bearer token.

Path parameters

ParameterTypeRequiredDescription
currency_idintegerYesThe currency ID

Query parameters

ParameterTypeRequiredDescriptionExample
includestringNoComma-separated list of relationships to include. Available options: company, creatorcurrency
filter[id]stringNoComma-separated list of IDs to filter by
filter[company_id]stringNoComma-separated list of company IDs to filter by
filter[name]stringNoFilter by rate date (YYYY-MM-DD)
sortstringYesSort fieldname
pageintegerYesPage number1
bash
curl -X GET "https://your-domain.com/admin/api/v1/support/currencies/{currency_id}/rates?include=currency&sort=name&page=1" \
  -H "Authorization: Bearer {YOUR_AUTH_TOKEN}" \
  -H "Accept: application/json" \
  -H "Content-Type: application/json"
javascript
const response = await fetch("https://your-domain.com/admin/api/v1/support/currencies/{currency_id}/rates?include=currency&sort=name&page=1", {
  method: "GET",
  headers: {
    "Authorization": "Bearer {YOUR_AUTH_TOKEN}",
    "Accept": "application/json",
    "Content-Type": "application/json",
  },
});

const data = await response.json();
console.log(data);
php
<?php

$client = new \GuzzleHttp\Client();

$response = $client->request('GET', 'https://your-domain.com/admin/api/v1/support/currencies/{currency_id}/rates?include=currency&sort=name&page=1', [
    'headers' => [
        'Authorization' => 'Bearer {YOUR_AUTH_TOKEN}',
        'Accept' => 'application/json',
        'Content-Type' => 'application/json',
    ],
]);

$data = json_decode($response->getBody(), true);

Create currency rate ​

POST /admin/api/v1/support/currencies/{currency_id}/rates

Create a new currency exchange rate for a specific currency

🔒 Requires a valid Bearer token.

Path parameters

ParameterTypeRequiredDescription
currency_idintegerYesThe currency ID

Body parameters

ParameterTypeRequiredDescription
namestringYesRate effective date (YYYY-MM-DD format). Must be a valid date.
ratenumberYesExchange rate (minimum 0). Must be at least 0.
company_idintegerNoCompany ID (optional, null for global rates). Must match an existing stored value.
bash
curl -X POST "https://your-domain.com/admin/api/v1/support/currencies/{currency_id}/rates" \
  -H "Authorization: Bearer {YOUR_AUTH_TOKEN}" \
  -H "Accept: application/json" \
  -H "Content-Type: application/json" \
  -d '{
  "name": "2024-01-15",
  "rate": 1.25,
  "company_id": 1
}'
javascript
const response = await fetch("https://your-domain.com/admin/api/v1/support/currencies/{currency_id}/rates", {
  method: "POST",
  headers: {
    "Authorization": "Bearer {YOUR_AUTH_TOKEN}",
    "Accept": "application/json",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "name": "2024-01-15",
  "rate": 1.25,
  "company_id": 1
}),
});

const data = await response.json();
console.log(data);
php
<?php

$client = new \GuzzleHttp\Client();

$response = $client->request('POST', 'https://your-domain.com/admin/api/v1/support/currencies/{currency_id}/rates', [
    'headers' => [
        'Authorization' => 'Bearer {YOUR_AUTH_TOKEN}',
        'Accept' => 'application/json',
        'Content-Type' => 'application/json',
    ],
    'json' => [
    'name' => '2024-01-15',
    'rate' => 1.25,
    'company_id' => 1,
  ],
]);

$data = json_decode($response->getBody(), true);
python
import requests

url = "https://your-domain.com/admin/api/v1/support/currencies/{currency_id}/rates"

headers = {
    "Authorization": "Bearer {YOUR_AUTH_TOKEN}",
    "Accept": "application/json",
    "Content-Type": "application/json",
}

    "name": "2024-01-15",
    "rate": 1.25,
    "company_id": 1,
}
