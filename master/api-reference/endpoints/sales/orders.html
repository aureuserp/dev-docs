Orders ​

Part of the Sales API. Base URL https://your-domain.com/admin/api/v1 — replace the host with your own installation and the token placeholder with a real Bearer token (see Authentication).

List orders ​

GET /admin/api/v1/sales/orders

Retrieve a paginated list of orders with filtering and sorting

🔒 Requires a valid Bearer token.

Query parameters

ParameterTypeRequiredDescriptionExample
includestringNoComma-separated list of relationships to include. Available options: partner, partnerInvoice, partnerShipping, user, team, company, currency, paymentTerm, fiscalPosition, journal, campaign, utmSource, medium, warehouse, lines, lines.product, lines.linkedSaleOrderSale, lines.uom, lines.productPackaging, lines.currency, lines.orderPartner, lines.salesman, lines.warehouse, lines.route, lines.companypartner,lines
filter[id]stringNoComma-separated list of IDs to filter by
filter[state]stringNoFilter by state
filter[partner_id]stringNoComma-separated list of partner IDs to filter by
filter[trashed]stringNoFilter by trashed status. Available options: with, onlywith
sortstringYesSort field-created_at
pageintegerYesPage number1
bash
curl -X GET "https://your-domain.com/admin/api/v1/sales/orders?include=partner%2Clines&filter%5Btrashed%5D=with&sort=-created_at&page=1" \
  -H "Authorization: Bearer {YOUR_AUTH_TOKEN}" \
  -H "Accept: application/json" \
  -H "Content-Type: application/json"
javascript
const response = await fetch("https://your-domain.com/admin/api/v1/sales/orders?include=partner%2Clines&filter%5Btrashed%5D=with&sort=-created_at&page=1", {
  method: "GET",
  headers: {
    "Authorization": "Bearer {YOUR_AUTH_TOKEN}",
    "Accept": "application/json",
    "Content-Type": "application/json",
  },

Create order ​

POST /admin/api/v1/sales/orders

Create a new order with line items

🔒 Requires a valid Bearer token.

Body parameters

ParameterTypeRequiredDescription
partner_idintegerYesCustomer (partner) ID. Must match an existing stored value.
payment_term_idintegerYesPayment term ID. Must match an existing stored value.
date_orderstringYesOrder date in YYYY-MM-DD format. Must be a valid date.
validity_datestringNoQuotation validity date in YYYY-MM-DD format. Must be a valid date.
commitment_datestringNoMust be a valid date.
client_order_refstringNoMust not be greater than 255 characters.
originstringNoMust not be greater than 255 characters.
notestringNoTerms and conditions or internal note.
user_idintegerNoMust match an existing stored value.
company_idintegerNoCompany ID. Must match an existing stored value.
currency_idintegerNoCurrency ID. Ignored when a price list is given, as the order then follows the price list currency. Must match an existing stored value.
price_list_idintegerNoPrice list ID. Its currency becomes the order currency, and its rules price any line sent without a unit price. Must match an existing stored value.
campaign_idintegerNoMust match an existing stored value.
utm_source_idintegerNoMust match an existing stored value.
medium_idintegerNoMust match an existing stored value.
sales_order_tagsinteger[]NoMust match an existing stored value.
linesobject[]YesArray of order line items with writable fields from the quotation form. Must have at least 1 items.
lines[].idintegerNoMust match an existing stored value.
lines[].product_idintegerYesMust match an existing stored value.
lines[].product_qtynumberYesMust be at least 0. Must not be greater than 99999999999.
lines[].qty_deliverednumberNoMust be at least 0. Must not be greater than 99999999999.
lines[].product_packaging_qtynumberNoMust be at least 0. Must not be greater than 99999999999.
lines[].price_unitnumberNoThis field is required when price_list_id is not present. Must be at least 0. Must not be greater than 99999999999.
lines[].discountnumberNoMust be at least 0. Must not be greater than 100.
lines[].customer_leadnumberNoMust be at least 0. Must not be greater than 99999999999.
lines[].product_uom_idintegerNoMust match an existing stored value.
lines[].product_packaging_idintegerNoMust match an existing stored value.
lines[].taxesinteger[]NoMust match an existing stored value.
