Rules ​

Part of the Inventory API. Base URL https://your-domain.com/admin/api/v1 — replace the host with your own installation and the token placeholder with a real Bearer token (see Authentication).

List rules ​

GET /admin/api/v1/inventories/rules

Retrieve a paginated list of rules with filtering and sorting

🔒 Requires a valid Bearer token.

Query parameters

ParameterTypeRequiredDescriptionExample
includestringNoComma-separated list of relationships to include. Available options: sourceLocation, destinationLocation, route, operationType, partnerAddress, warehouse, propagateWarehouse, company, creatorroute,operationType
filter[id]stringNoComma-separated list of IDs to filter byarchitecto
filter[name]stringNoFilter by nameReplenish
filter[action]stringNoFilter by action valuespull
filter[source_location_id]stringNoFilter by source location IDsarchitecto
filter[destination_location_id]stringNoFilter by destination location IDsarchitecto
filter[route_id]stringNoFilter by route IDsarchitecto
filter[operation_type_id]stringNoFilter by operation type IDsarchitecto
sortstringNoSort field-created_at
bash
curl -X GET "https://your-domain.com/admin/api/v1/inventories/rules?include=route%2CoperationType&filter%5Bid%5D=architecto&filter%5Bname%5D=Replenish&filter%5Baction%5D=pull&filter%5Bsource_location_id%5D=architecto&filter%5Bdestination_location_id%5D=architecto&filter%5Broute_id%5D=architecto&filter%5Boperation_type_id%5D=architecto&sort=-created_at" \
  -H "Authorization: Bearer {YOUR_AUTH_TOKEN}" \
  -H "Accept: application/json" \
  -H "Content-Type: application/json"
javascript
const response = await fetch("https://your-domain.com/admin/api/v1/inventories/rules?include=route%2CoperationType&filter%5Bid%5D=architecto&filter%5Bname%5D=Replenish&filter%5Baction%5D=pull&filter%5Bsource_location_id%5D=architecto&filter%5Bdestination_location_id%5D=architecto&filter%5Broute_id%5D=architecto&filter%5Boperation_type_id%5D=architecto&sort=-created_at", {

Create rule ​

POST /admin/api/v1/inventories/rules

Create a new rule

🔒 Requires a valid Bearer token.

Body parameters

ParameterTypeRequiredDescription
namestringYesRule name. Must not be greater than 255 characters.
actionstringYesRule action.
operation_type_idintegerYesOperation type ID. Must match an existing stored value.
source_location_idintegerYesSource location ID. Must match an existing stored value.
destination_location_idintegerYesDestination location ID. Must match an existing stored value.
partner_address_idintegerNoPartner address ID. Must match an existing stored value.
delayintegerNoLead time in days. Must be at least 0.
route_idintegerYesRoute ID. Must match an existing stored value.
company_idintegerNoCompany ID. Must match an existing stored value.
bash
curl -X POST "https://your-domain.com/admin/api/v1/inventories/rules" \
  -H "Authorization: Bearer {YOUR_AUTH_TOKEN}" \
  -H "Accept: application/json" \
  -H "Content-Type: application/json" \
  -d '{
  "name": "WH1: Stock -> Output",
  "action": "pull",
  "operation_type_id": 1,
  "source_location_id": 3,
  "destination_location_id": 4,
  "partner_address_id": 10,
  "delay": 1,
  "route_id": 1,
  "company_id": 1
}'
javascript
const response = await fetch("https://your-domain.com/admin/api/v1/inventories/rules", {
  method: "POST",
  headers: {
    "Authorization": "Bearer {YOUR_AUTH_TOKEN}",
    "Accept": "application/json",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "name": "WH1: Stock -> Output",
  "action": "pull",
  "operation_type_id": 1,
  "source_location_id": 3,
  "destination_location_id": 4,
  "partner_address_id": 10,
  "delay": 1,
  "route_id": 1,
  "company_id": 1
}),
});

const data = await response.json();
console.log(data);
