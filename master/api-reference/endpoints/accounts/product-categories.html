Product Categories ​

Part of the Accounts API. Base URL https://your-domain.com/admin/api/v1 — replace the host with your own installation and the token placeholder with a real Bearer token (see Authentication).

List categories ​

GET /admin/api/v1/accounts/categories

Retrieve a paginated list of product categories with filtering and sorting

🔒 Requires a valid Bearer token.

Query parameters

ParameterTypeRequiredDescriptionExample
includestringNoComma-separated list of relationships to include. Available options: parent, children, creator, propertyAccountIncome, propertyAccountExpense, propertyAccountDownPaymentparent,propertyAccountIncome
filter[id]stringNoComma-separated list of IDs to filter by
filter[name]stringNoFilter by category name (partial match)
filter[parent_id]stringNoComma-separated list of parent IDs to filter by
sortstringYesSort fieldname
pageintegerYesPage number1
bash
curl -X GET "https://your-domain.com/admin/api/v1/accounts/categories?include=parent%2CpropertyAccountIncome&sort=name&page=1" \
  -H "Authorization: Bearer {YOUR_AUTH_TOKEN}" \
  -H "Accept: application/json" \
  -H "Content-Type: application/json"
javascript
const response = await fetch("https://your-domain.com/admin/api/v1/accounts/categories?include=parent%2CpropertyAccountIncome&sort=name&page=1", {
  method: "GET",
  headers: {
    "Authorization": "Bearer {YOUR_AUTH_TOKEN}",
    "Accept": "application/json",
    "Content-Type": "application/json",
  },
});

const data = await response.json();
console.log(data);
php
<?php

$client = new \GuzzleHttp\Client();

$response = $client->request('GET', 'https://your-domain.com/admin/api/v1/accounts/categories?include=parent%2CpropertyAccountIncome&sort=name&page=1', [
    'headers' => [
        'Authorization' => 'Bearer {YOUR_AUTH_TOKEN}',
        'Accept' => 'application/json',
        'Content-Type' => 'application/json',
    ],
]);

$data = json_decode($response->getBody(), true);
python
import requests

url = "https://your-domain.com/admin/api/v1/accounts/categories?include=parent%2CpropertyAccountIncome&sort=name&page=1"

headers = {
    "Authorization": "Bearer {YOUR_AUTH_TOKEN}",
    "Accept": "application/json",
    "Content-Type": "application/json",
}

response = requests.get(url, headers=headers)

data = response.json()
print(data)

Create category ​

POST /admin/api/v1/accounts/categories

Create a new product category with accounting properties

🔒 Requires a valid Bearer token.

Body parameters

ParameterTypeRequiredDescription
namestringYesCategory name (max 255 characters). Must not be greater than 255 characters.
parent_idintegerNoParent category ID for nested categories. Must match an existing stored value.
property_account_income_idintegerNoIncome account ID for this category. Must match an existing stored value.
property_account_expense_idintegerNoExpense account ID for this category. Must match an existing stored value.
property_account_down_payment_idintegerNoDown payment account ID for this category. Must match an existing stored value.
bash
curl -X POST "https://your-domain.com/admin/api/v1/accounts/categories" \
  -H "Authorization: Bearer {YOUR_AUTH_TOKEN}" \
  -H "Accept: application/json" \
  -H "Content-Type: application/json" \
  -d '{
  "name": "Electronics",
  "parent_id": 1,
  "property_account_income_id": 1,
  "property_account_expense_id": 2,
  "property_account_down_payment_id": 3
}'
javascript
const response = await fetch("https://your-domain.com/admin/api/v1/accounts/categories", {
  method: "POST",
  headers: {
    "Authorization": "Bearer {YOUR_AUTH_TOKEN}",
    "Accept": "application/json",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "name": "Electronics",
  "parent_id": 1,
  "property_account_income_id": 1,
  "property_account_expense_id": 2,
  "property_account_down_payment_id": 3
}),
});

const data = await response.json();
console.log(data);
php
<?php

$client = new \GuzzleHttp\Client();

$response = $client->request('POST', 'https://your-domain.com/admin/api/v1/accounts/categories', [
    'headers' => [
        'Authorization' => 'Bearer {YOUR_AUTH_TOKEN}',
        'Accept' => 'application/json',
        'Content-Type' => 'application/json',
    ],
    'json' => [
    'name' => 'Electronics',
    'parent_id' => 1,
    'property_account_income_id' => 1,
    'property_account_expense_id' => 2,
    'property_account_down_payment_id' => 3,
  ],
]);

$data = json_decode($response->getBody(), true);
